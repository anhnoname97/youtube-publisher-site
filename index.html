Video Publisher

A personal desktop tool. Last updated: October 28, 2026.

Video Publisher is a private application that runs only on its owner's Windows computer. It uploads videos from the owner's local video library to the owner's own YouTube channel on a schedule the owner configures.

What it does

  • Reads finished video files and their titles, descriptions and hashtags from a folder on the same computer.
  • Uploads those videos to the connected YouTube channel through the official YouTube Data API v3, using the visibility and publish time the owner sets.
  • Reads back the upload and processing status of videos it uploaded, so the owner can see whether each one was published.

Who can use it

The application is not offered to the public. It has no website login, no server and no user accounts. Only the owner of the computer, signed in with their own Google account, connects a channel.

Google and YouTube

This application uses YouTube API Services. By connecting a channel you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.
